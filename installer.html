BOOKMARKLET LOADER

도구를 고른 뒤, 아래 버튼을 북마크바로 드래그해 설치합니다.

1. 도구 선택

ENV SWITCH Admin Grid Export SlickGrid Export Page QR Multilang Fill Glitch FX
BOOKMARKLET LOADER 위 정보를 입력하면 활성화됩니다 드래그 → 북마크바
필수 항목을 입력해 주세요

2. 북마클릿 설치

  1. 북마크바가 보이지 않으면 먼저 표시합니다 (Ctrl/Cmd + Shift + B).
  2. 모든 항목을 입력하면 위 버튼이 활성화됩니다.
  3. 활성화된 버튼을 북마크바로 드래그합니다. 북마크 이름은 버튼에 표시된 이름이 됩니다. 드래그가 안 되면 북마크바를 우클릭 → 페이지 추가 → URL 칸에 이 버튼의 링크 주소를 붙여넣습니다.

3. 동작 방식

동적 로딩 구조
  • 북마클릿 자체는 <script src="...">를 삽입하는 로더 코드뿐입니다 (수백 바이트 수준). 실제 로직은 클릭할 때마다 지정한 URL에서 새로 불러옵니다.
  • 저장소는 반드시 공개(public)여야 인증 없이 파일을 불러올 수 있습니다.
  • URL은 https://cdn.jsdelivr.net/gh/{계정}/{저장소}@{브랜치}/{파일} 형식이며, 로더가 실행될 때마다 &t=현재시각을 붙여 최신 파일을 불러옵니다.
  • 푸시 직후에도 jsDelivr 서버 쪽 캐시가 남아 있으면 위의 캐시 퍼지 버튼으로 비웁니다.
