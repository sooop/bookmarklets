3. 북마클릿 설치

  1. 북마크바가 보이지 않으면 먼저 표시합니다 (Ctrl/Cmd + Shift + B).
  2. 모든 항목을 입력하면 위 버튼이 활성화됩니다.
  3. 활성화된 버튼을 북마크바로 드래그합니다. 드래그가 안 되면 북마크바를 우클릭 → 페이지 추가 → URL 칸에 이 버튼의 링크 주소를 붙여넣습니다.

4. 동작 방식

동적 로딩 구조
  • 북마클릿 자체는 <script src="...">를 삽입하는 로더 코드뿐입니다 (수백 바이트 수준). 실제 로직은 클릭할 때마다 지정한 URL에서 새로 불러옵니다.
  • 저장소는 반드시 공개(public)여야 인증 없이 파일을 불러올 수 있습니다.
URL 유형
  • jsDelivr: https://cdn.jsdelivr.net/gh/{계정}/{저장소}@{브랜치}/{파일} — CDN을 거치며 콘텐츠 타입이 안정적입니다.
  • raw.githubusercontent.com: https://raw.githubusercontent.com/{계정}/{저장소}/{브랜치}/{파일} — GitHub에서 직접 서빙하며, jsDelivr의 CDN 캐시 지연 없이 커밋 직후 바로 반영됩니다.
캐시 파라미터
  • 타임스탬프: 로더가 실행될 때마다 &t=현재시각을 자동으로 붙여, 매번 확실히 최신 파일을 불러옵니다.
  • 버전: 입력한 값을 &v=값으로 URL에 고정합니다. 파일을 갱신할 때마다 이 값을 바꿔주면 캐시를 우회할 수 있고, 값을 바꾸지 않으면 캐시된 버전이 계속 재사용됩니다.
