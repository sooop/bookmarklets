Bookmarklet

ENV SWITCH

*.tracxlogis.com, *.qxpress.net 페이지에서 실행하면 Production / Staging / VM 환경으로 현재 경로를 유지한 채 이동합니다. 실제 로직은 GitHub 등에 올려둔 env-switch.js를 매번 새로 불러와 실행하는 방식이라, 북마클릿 자체는 아주 작고 스크립트를 갱신해도 다시 설치할 필요가 없습니다.

1. 스크립트 호스팅

  1. GitHub에 (공개) 저장소를 만들고 env-switch.js 파일을 커밋합니다.
  2. jsDelivr 형식으로 URL을 만듭니다: https://cdn.jsdelivr.net/gh/{계정}/{저장소}@{브랜치}/env-switch.js
  3. 예시: https://cdn.jsdelivr.net/gh/sooop/bookmarklets@main/env-switch.js
URL을 입력하면 아래 북마클릿이 활성화됩니다
ENV SWITCH P · S · V 환경 전환기 드래그 → 북마크바
위 버튼을 브라우저 북마크바로 드래그하세요

2. 북마클릿 설치

  1. 북마크바가 보이지 않으면 먼저 표시합니다 (Ctrl/Cmd + Shift + B).
  2. 위 URL 입력창에 스크립트 주소를 넣으면 "ENV SWITCH" 버튼이 활성화됩니다.
  3. 활성화된 버튼을 북마크바로 드래그합니다. 드래그가 안 되면 북마크바를 우클릭 → 페이지 추가 → URL 칸에 이 버튼의 링크 주소를 복사해 붙여넣습니다.

3. 사용

  1. tracxlogis.com 또는 qxpress.net 도메인 페이지에서 북마크릿을 클릭합니다.
  2. 화면에 뜨는 패널에서 이동할 환경을 선택합니다 (클릭 또는 단축키).
  3. 같은 경로(pathname, 쿼리, 해시)를 유지한 채 선택한 환경으로 이동합니다.
P
Production
S
Staging
V
VM

4. 동작 방식

동적 로딩 구조
  • 북마클릿 자체는 <script src="...">를 삽입하는 로더 코드뿐입니다 (수백 바이트 수준).
  • 클릭할 때마다 호스팅된 env-switch.js를 캐시버스팅 쿼리(?t=timestamp)와 함께 새로 불러오므로, 파일만 업데이트하면 북마클릿을 재설치하지 않아도 즉시 반영됩니다.
  • 저장소는 반드시 공개(public)여야 인증 없이 raw 파일을 불러올 수 있습니다.
  • 이 방식은 매번 원격 스크립트를 실행하는 구조이므로, 저장소 접근 권한 관리에 유의해 주세요.
변환 규칙
  • Production ↔ Staging: A.tracxlogis.com ↔ staging-A.tracxlogis.com (qxpress.net도 동일)
  • VM: 기본값은 sooop-dev.tracxlogis.com:3002이며, 패널의 연필 아이콘을 눌러 서브도메인과 포트를 직접 바꿀 수 있습니다.
VM 설정 저장
  • VM 행 옆 연필 아이콘을 누르면 서브도메인/포트 입력창이 열립니다.
  • 입력한 값은 즉시 localStorage에 저장되어, 다음 실행부터 계속 유지됩니다.
서브도메인(A) 기억
  • Production이나 Staging 페이지에서 실행하면 서브도메인(A)을 localStorage에 저장해 둡니다.
  • VM 페이지에는 서브도메인 정보가 없으므로, VM에서 실행할 때는 저장된 값을 불러와 사용합니다.
  • 저장된 값이 아예 없으면(한 번도 Production/Staging을 방문한 적 없는 경우) 기본값인 smartship2.tracxlogis.com을 사용합니다.
